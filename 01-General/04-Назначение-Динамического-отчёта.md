A Dynamic Report is a form of user-defined report developed for Roin World. The System obtains the report launch criteria (filters) from the active document.  
Usage specifics:

* The report will be generated only if the document form is active and the document has already been added to the database.
* Report launch can be assigned to keys F2 through F12.
* When working on a laptop with function keys, depending on the operating-system settings, pressing the Fn key together with the relevant Fx key may be required.

## Assigning a shortcut to launch a report

To configure the shortcut:

1. From the horizontal menu, go to Tools → User Shortcuts → Customize.

 <img src="../.assets/4f64ef81-212d-45ba-ad05-caeb6ba6baba.png" alt="" width="100%" />

2. In the window that opens, select the key to which the report launch will be assigned.

   <img src="../.assets/146aea01-1f80-4cd2-bbef-593de0cdc4a2.png" alt="" width="100%" />

## Launching a Dynamic Report

1. Open a document that has already been saved in the database (for example, a Sales Quotation).

2. Make sure the document is active (after opening the document, do not click another form or application).

3. Press the Fx key combination assigned to the report.
