All postings in the System are recorded in parallel using the local currency (EGP) and the system currency (SYS), which is associated with USD.  
For this reason, work cannot begin until the exchange rate for the current day has been entered.  
When any document that can create an accounting posting is opened, the Exchange Rates and Indexes window will be displayed. To continue working, the user must enter the required currency rates.

Exchange-rate source: [https://www.cbe.org.eg/en/economic-research/statistics/cbe-exchange-rates/historical-data](https://www.cbe.org.eg/en/economic-research/statistics/cbe-exchange-rates/historical-data)

**(!) It is important to enter the correct rate. Otherwise, all postings created during the day using an incorrect rate will need to be reversed and entered again.**

##  
Exchange-rate entry concept

The exchange rate is entered daily at the start of the working day. The rate is then updated in the exchange-rate table at 14:30.

## Entering exchange rates

1. From the Main Menu, open → Administration → Exchange Rates and Indexes.

<img src="../.assets/e0fdca96-83f0-4e1b-8b1d-b1da770f0b96.png" alt="" width="100%" />

2. In the window that opens, enter the current rates for all currencies in the row for the current date.

If there are gaps (weekends), the rates for those dates must also be entered.  
For SYS, enter the USD-to-EGP exchange rate.  
<img src="../.assets/601b87bc-58ae-41e9-b617-93baef5961c6.png" alt="" width="100%" />

3. Save the changes by clicking [Update].
