This example describes the process for mass updating Bills of Materials. It specifically shows how to change the calculation Price List and refresh component prices. Other BOM changes are performed in the same way. For example, a new component (such as packaging) can be added or an ingredient can be replaced.

Please note:

* changing the assigned price list changes the **estimated** cost of the Product. The actual cost of each manufactured Product is not taken from the price list; it is based on the actual cost of the components used in production.
* changes made to a Bill of Materials do not affect Production Orders that have already been created from that BOM. The changes will be applied to the next Production Order created.

## Concept of mass BOM updates
 <img src="../.assets/3730cfb5-c401-485e-b521-ecd58a84a9ea.png" alt="" width="100%" />

To update the price list used to calculate the total Product cost:

1. From the Main Menu, open Production → Bill of Materials Management.

 <img src="../.assets/a754c49b-af37-44f8-a064-4a255c01d0da.png" alt="" width="100%" />

2. The System opens the criteria-selection form. To update the price list:

(1) Select the type of change. Choose either 'Change Bill of Materials Rows' or 'Change Bill of Materials Header' depending on the specific requirement.  
(2) Select BOMs without routing.  
(3) Select the checkbox and choose the price list to be assigned to the BOMs.  
Additional filtering criteria can also be specified if required.

 <img src="../.assets/b707a9e0-0cfe-402d-96f6-24f731af83a0.png" alt="" width="100%" />

3. Click [OK].

4. The System opens a preview window.

 <img src="../.assets/90993c92-65dd-4b0d-8f02-d916cf845fd0.png" alt="" width="100%" />

5. Review the list and, if necessary, clear the checkbox for items that should not be updated.

(The table columns show the current value and the value that will be assigned.)

 <img src="../.assets/a3d3da19-3686-4867-b080-9ceda5a957ec.png" alt="" width="100%" />

6. Click [OK].

7. Wait for the update to complete.

8. When the update is complete, the result will be shown in the Status Bar.
