An A/R Credit Memo is a document that reduces Accounts Receivable. It can be created with a reverse inventory movement (return) or without inventory movement.  
An A/R Credit Memo can reverse an A/R Invoice either fully or partially.

To create an A/R Credit Memo:

1. Open A/R Credit Memo from Main Menu → Sales - A/R → A/R Credit Memo.

   <img src="../.assets/746ef62b-3bd9-426f-9f7e-59988c6d6c68.png" alt="" width="100%" />

2. Complete the Header:

(1) Customer Code or Name  
(2) Credit Memo posting date  
<img src="../.assets/e1ff5875-d1e4-44bb-a1ca-53b7ef999e04.png" alt="" width="100%" />

3. Click [Copy From] and select A/R Invoices from the drop-down list.

 <img src="../.assets/79f62522-1fa5-4ddd-8231-65d1c9983bab.png" alt="" width="100%" />

4. The System opens a list of available base documents. Double-click the required document. To select multiple documents, hold [Ctrl]+[Shift].

 <img src="../.assets/b23869ae-3a12-4c05-acc2-16bf9a54f01a.png" alt="" width="100%" />

5. The System opens the Draw Document Wizard.

<img src="../.assets/ecee84ce-b501-40a8-85cd-d063298f0a2f.png" alt="" width="100%" />

6. Specify the required document-creation rules. If only a partial correction of the A/R Invoice is required, select the Choose option.

Click [Next].

7. For a partial correction, select the rows to be corrected and click [Finish].

<img src="../.assets/21fcba61-6208-4290-88f0-4bb2fb6a71b0.png" alt="" width="100%" />

8. If the base A/R Invoice uses grouping, the data will be copied to the A/R Credit Memo with the same grouping.  
<img src="../.assets/42ee8294-b359-4042-9659-7299ef651c9a.png" alt="" width="100%" />

9. Remove the grouping to display the item list.

<img src="../.assets/701aca29-2c89-4c61-9ef8-19c9ed4a40d1.png" alt="" width="100%" />

10. Depending on the purpose of the correction, adjust the row data:

Change the quantity if items are being returned to the warehouse,  
or  
select [Without Qty Posting] if the goods should not be returned to inventory and only the price/receivable needs to be corrected.  
<img src="../.assets/3d3cdcb1-4572-4248-b105-7748e66723b1.png" alt="" width="100%" />

11. Perform a preliminary validation by generating a Journal Entry Preview. This runs document-rule validation.

Click [Journal Entry Preview] on the Tool Panel.

 <img src="../.assets/e9aad3a2-0b17-4a25-859f-30b282d57710.png" alt="" width="100%" />

If the System opens the Journal Entry form, the document has passed validation. Verify that the generated entry is correct.

12. Return to the document and click [Add] to post the A/R Credit Memo.
