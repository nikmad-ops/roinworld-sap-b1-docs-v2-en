The Profit and Loss Statement (P&L) is located under:  
Main Menu → Financials → Financial Reports → Financial → Profit and Loss Statement

 <img src="../../.assets/2a170088-cc4e-4c4e-a7d9-0f33f8c491d5.png" alt="" width="100%" />

1. Before opening the report, the System displays the Selection Criteria form, where posting-selection rules and report layout must be defined.

<img src="../../.assets/a3ac4171-88a9-4861-9823-d054f6d50b62.png" alt="" width="100%" />

(1) Posting dates to be included in the report  
(2) Account display settings and the way accounts will be presented  
(3) Report column contents and, if applicable, the report template  
(4) Extended criteria  

Extended criteria include, among other things, generating the report for specific cost centers. For example, the P&L can be generated only for cost center KT-Kitchen.  
 <img src="../../.assets/4e0ba462-36cc-4b47-915c-4d01e0d69df8.png" alt="" width="100%" />(!) Please note: selection criteria are saved at System level, not per user. This means that if a colleague previously ran the report for a specific cost center, those settings may already be selected when you open the report.

2. After setting the criteria, click [OK].

3. The Profit and Loss Statement opens. By default, the report opens using a template with summary rows. To choose the level of detail, change the account level. For Roin World, all active accounts are loaded at level 5.

<img src="../../.assets/873cfab8-d4da-4fba-8209-f3c26e70e243.png" alt="" width="100%" />

4. To hide the summary/header rows, select [Hide Titles].

<img src="../../.assets/5a988fd5-1e91-4a30-ac41-142ed3c3b17e.png" alt="" width="100%" />

In this example, the selection criteria specify amounts in Local Currency in the first column and System Currency (SYS), which corresponds to USD, in the second column. Because the System records transactions in both currencies in parallel, every transaction is reflected in EGP and SYS. The SYS exchange rate used is the rate valid on the document date.
